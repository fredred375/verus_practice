# verus_practice

## Intro

This repository is a practice/example on understanding how verified code and unverified code is handled in the anvil project.

You can find `README.md` files and comments that document my understanding of this project.

## Prerequisites

- rust
- verus

## Usage

You will need to specify your verus binary location.
```bash
VERUS_DIR=<path to your verus build>
```

Then,
```bash
./build.sh
```
